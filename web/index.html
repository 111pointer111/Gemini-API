重新连接 Gemini

当状态显示 UNAUTHENTICATED 时，复制浏览器里正在使用的完整 Cookie。

  1. 在 Chrome 打开 gemini.google.com 并确认网页可正常对话。
  2. 按 ⌥⌘I 打开开发者工具，进入 Network。
  3. 刷新页面，点击一个 batchexecute 请求。
  4. 在 Headers → Request Headers 找到 Cookie，复制冒号后面的完整内容。
  5. 粘贴到右侧并测试。不要复制 Set-Cookie。

Cookie 等同登录凭证。它只会保存到本机权限为 0600 的 Git-ignored 文件，不会显示或上传到仓库。

保存前会实时连接 Gemini 验证，不可用的 Cookie 不会替换当前配置。
